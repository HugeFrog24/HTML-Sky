# HT's Mod Loader (single-mod fork)
Use HTML to execute code before the game does.

> **Archived.** This loader now lives in the Tibik source tree at
> [`HugeFrog24/libtibik-srctree`](https://github.com/HugeFrog24/libtibik-srctree)
> under `pc/loader/`, built there with CMake beside the mod it serves. This
> repository is kept read-only as the record of its history; new work happens
> in that tree. For the general-purpose loader that runs any mod, use
> [upstream](https://github.com/HTMonkeyG/HTML-Sky).

This is a fork of [HT's Mod Loader](https://github.com/HTMonkeyG/HTML-Sky)
modified to load exactly one mod. Upstream scans the mods folder, resolves
dependencies between the mods it finds and loads them all; this build looks only
for the `tibik` folder under `mods`, loads what is there, and ignores every
other folder. For the general-purpose loader that runs any mod, use upstream.

**This project and its derivatives are only intented to be used for learning purposes. This repository won't contain any anti-anti-cheat.**

**The responsibility arising from the use of this project and its derivatives in multiplayer games shall be borne by the users themselves.**

## Usage
**This project is designed to work exclusively with assembly logic code generated by compiled languages. Execution on interpreted languages or bytecode virtual machine executables may cause unexpected results.**

1. Put `winhttp.dll` together with the game's executable (e.g. `Sky.exe`).
2. Create an `htmodloader` folder beside `Sky.exe`, and place the mod in a `tibik` folder inside it. Your directory should look like this:
```
<Game installation directory>
 ├─Sky.exe
 ├─htmodloader
 │ └─mods
 │   └─tibik
 │     ├─manifest.json   (or an HTMODMANIFEST resource inside the DLL)
 │     └─<mod executable>.dll
 ├─html-config.json
 ├─winhttp.dll
 └─<...>
```
3. Start the game. The loaded mod, or the reason it did not load, is shown in the `Mods` tab of the `HTML Main Menu`.

The folder must be named `tibik` and the DLL inside it must identify as `tibik`; a folder by any other name, or a DLL claiming another package, is ignored. The Tibik launcher is an installer that lays all of this out for you.

## Build
Built with MinGW-w64 GCC 16.1.0 (MinGW-Builds, posix-seh) and GNU Binutils 2.46.
1. Clone the repository.
2. Change the working directory to `HTML-Sky`, then execute `mingw32-make.exe SHELL=cmd.exe all` on the first compilation. The recipes use cmd.exe commands, so run it through cmd even from a POSIX shell.

## What this fork removes
The multi-mod machinery has no work to do with a single tenant, so it is gone rather than left dormant:

- The mods folder is not scanned; only the `tibik` folder is opened. Dependency resolution and duplicate handling go with it.
- The mod-facing API is reduced to what the one mod imports. The version and game-status queries, cross-mod handles and manifests, custom options, the path helpers, the ImGui context hand-off (`HTImGuiDispatch`) and the last-error slot are removed, along with the LevelDB datastore and the in-game console.
- The `Mods` tab reports that one mod's status; the `Console` tab is gone.

To write and load your own mod, use [upstream](https://github.com/HTMonkeyG/HTML-Sky), which keeps all of the above.
